# 下一步路线（2026-11-12）

首版继续以小鼠 E7.0 单样本 GSM8559287 为正式基准。现有 RNA 主流程、报告和注释直接保存已经可运行，接下来先补齐可用性和验收。

## 1. 已实现：界面内调整 QC 参数并预览

质控页现已支持最低/最高检出基因数和线粒体比例阈值的启停与数值输入，展示过滤原因及保留数量；参数变化后重新确认，运行时保存配置快照。源 YAML 不会因界面操作而改写。

验收：不手动编辑 YAML 即可完成参数预览；预览结果与真正运行一致；不自动把示例阈值视为科学推荐。

2026-11-13：真实小鼠界面验证得到预览与运行一致的 8,813 个保留细胞，配置快照匹配界面值。

## 2. 已实现：聚类、marker 与注释联动

按聚类筛选 marker、查看单基因分布、显示当前候选注释及证据，让用户更容易完成已有的直接编辑保存流程。原聚类编号和候选细胞类型分别保留；每次注释修改均可追溯。

2026-11-13：联动选择、基因符号/ID搜索和分块读取已完成；开发环境与独立环境的29项测试通过，真实Ttr检出比例与原始计数结果一致。

## 3. 完成科研与软件验收

软件侧建立干净环境安装和自动测试，更新包含最新编辑功能的安装包；科学侧取得原始处理方法、参考基因组/注释版本、混样胚胎数及 doublet 处理信息，复核 QC 与候选细胞类型。当前缺失资料见 `E7.0_source_review.md`。

原始协议资料缺失只阻碍相应科学验收，可用性开发仍可推进。用户若能通过机构获取协议全文或样本处理配置，可与开发并行提供。
