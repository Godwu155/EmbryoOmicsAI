# EmbryoOmics AI — 产品需求文档（PRD v0.1）

日期：2026-09-27。状态：**讨论草案**。项目性质：教学与研究复现原型；项目名暂定。

## 1. 背景与目标

围绕**小鼠胚胎发育阶段**建立多组学证据图谱，最终比较表观遗传状态、单细胞 RNA 和**质谱蛋白质组丰度**随阶段的变化。v0.1 先提供从处理后的**原始基因计数矩阵**到质控、聚类、候选注释和证据报告的可重复流程。保留每项参数和人工审核记录，为蛋白组和表观遗传数据接入建立可靠基础。

### v0.1 成功定义

用户能导入一个支持格式的小鼠胚胎 RNA 样本及必要元数据；程序验证数据、完成可配置 QC 与 Scanpy 基础流程、输出交互报告和机器可读结果。无法支持的结论应显示“证据不足”，不得自动写成确定的细胞类型或调控机制。

### 用户

- 学生：借助公开数据学习分析步骤，能够查看输入、参数、输出和错误。
- 研究者/导师：快速检查数据质量和候选细胞群，保留人工决定权。

## 2. 实验对象与输入边界

- 第一演示数据：GEO [GSE278981](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE278981) 中选定的处理后小鼠胚胎 scRNA-seq 原始 UMI 矩阵。首次演示以一个样本为准；多个阶段的联合图需验证样本、阶段和批次信息。该数据的 E7.5 取自胚胎后部，不能无说明地与整胚蛋白组配成一个样本。
- 必填：矩阵与细胞/基因 ID；物种为小鼠，样本 ID，发育阶段，数据来源。可选：胚胎 ID、测序批次、已有真实细胞类型标签。
- 支持：10x `matrix.mtx[.gz]`＋`features.tsv[.gz]`＋`barcodes.tsv[.gz]` 文件夹；或明确指定原始计数层的 `.h5ad`。大体量矩阵采用稀疏格式。CSV 仅可作为小型演示，须显式声明行列方向。
- 不自动从基因名猜物种/阶段；不把细胞 ID 相似视为同胚胎或多组学配对证据。用户已明确“蛋白”指蛋白质组，后续蛋白层优先指质谱定量蛋白丰度，磷酸化蛋白组单列，不以组蛋白修饰或 CITE-seq 抗体面板冒充全蛋白质组。

## 3. 用户任务与验收

| ID | 用户要完成的任务 | 验收观察点 |
| --- | --- | --- |
| F01 | 导入并核查数据 | 显示样本、细胞、基因数量；验证 ID 唯一、非负整数计数、元数据匹配；错误有可操作说明 |
| F02 | 检查 QC 并决定阈值 | 分样本显示计数、基因数、可计算时的线粒体比例；预览过滤前后保留细胞数；阈值可修改并记录 |
| F03 | 跑可重复的 RNA 基础流程 | 自动完成规范化、HVG、PCA、邻居图、Leiden、UMAP；记录随机种子、软件版本和参数 |
| F04 | 查看候选细胞群 | 展示按 cluster、阶段、样本着色的图和 marker 表；用户可以填写注释、支持与冲突证据，允许“未知” |
| F05 | 下载和复查结果 | 提供 HTML 报告、CSV、配置和结果对象；报告注明数据来源、有效样本与人工未确认项 |
| F06 | 可选 AI 报告草稿 | 仅接受汇总统计、marker 和来源信息；逐条标注对应数据；模型不可覆盖人工注释，关闭 AI 时全流程可运行 |

## 4. 最小界面

1. **数据页**：上传/选择本地处理文件，填写物种、样本、阶段、数据来源；显示验证结果。
2. **QC 页**：按样本展示直方图和过滤预览；用户确认配置后才运行分析。
3. **结果页**：图表、marker 表、注释编辑区和待审核标记。
4. **报告页**：运行清单、图表、候选结论、限制、下载入口。

首版建议本地 Streamlit 单进程实现，配合独立命令行分析核心；避免同时维护 FastAPI 和 Streamlit 两套入口。

## 5. 不包含在 v0.1 中

FASTQ 比对与 Cell Ranger、质谱原始文件重新搜库、数据共享账号系统、跨物种注释、默认自动真值标注、发育轨迹与因果推断、RNA＋ATAC＋蛋白三模态自动整合。v0.1 的“AI”仅是**有证据边界的可选解释层**。

## 7. 关键质量标准

- 所有图表可追溯到输入文件、样本、过滤决定与配置；不能仅输出“准确率 0.86”而无校准或标注真值。
- 不把每个细胞当生物学重复；需要群间统计时先确认胚胎/样本重复。蛋白组多个细胞不对应的质谱值不能赋给单个细胞。来自不同研究的同阶段数据只可做有条件的阶段对照，不能做同胚胎相关性推断。
- 不默认跨阶段混合后直接解释为轨迹；UMAP 不表示时间方向。
- 出现空结果、线粒体基因未识别、标签缺失或数据已经归一化时显示明确提示，并阻止错误步骤。

## 8. 决策待确认

**已确认：研究胚胎发育阶段；蛋白指蛋白质组。**工作假设为小鼠、原肠胚阶段，待导师确认重点是 E7.5 左右还是更宽的时间序列，以及有无实验室自有数据。还需确认质谱定量技术、独立胚胎/混样重复、取材部位、允许的计算资源与目标交付日期。这些答案影响 v0.2+，不阻塞 v0.1 的单样本本地复现。
