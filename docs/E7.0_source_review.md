# E7.0 来源核对与解释边界（2026-11-12）

2026-11-13 双细胞复核：GSM8559287 官方记录描述每样本一个 10x 通道，目标产出约 10,000 个细胞，但 Data processing 仍仅指向 Aryamanesh 2022 协议，未明确陈述 doublet 去除方法。不得把 filtered_feature_bc_matrix 文件名理解为已去除 doublet。Scrublet 配置继续记录 upstream_handling: unknown；软件敏感性试验不能补足原始处理证据。

## 原始处理方法

[GSM8559287 官方记录](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM8559287) 指明小鼠胚胎、10x 单细胞 RNA 数据，并将处理方法指向 [Aryamanesh 2022 协议](https://doi.org/10.1007/978-1-0716-2281-0_10)。当前可访问的出版社页面仅公开摘要，全文需要订阅或机构访问。因此不能声称目前的 Scanpy 配置复现了作者的全部处理步骤。

公开条目的 Assembly 字段是 ARC mice，这不是明确的参考基因组版本。不能据此填为 mm10 或 GRCm39。独立胚胎数和混样方式仍保持未知，细胞数不当作胚胎重复数。

## 参考 marker 的用途

[Pijuan-Sala 等 2019](https://doi.org/10.1038/s41586-019-0933-9) 用 Ttr 和 Mixl1 分别研究脏内胚层来源与原条来源的内胚层过程，可作为候选参考，不能凭单基因给当前聚类定名。

[原肠胚空间图谱](https://pmc.ncbi.nlm.nih.gov/articles/PMC7618461/) 描述了 Pou5f1、Dnmt3a、Dnmt3b 以及 Sp5、T、Lhx1、Sox17、Foxa2 等在特定空间细胞群中的表达。这里仅查看这些基因在本数据中的检出比例，不将跨研究 marker 直接当成真值标签。

Spink1、Apoe 列入观察面板是因为它们出现在本数据待核查聚类的前列 marker 中，不以此单独定义细胞类型。marker 面板不穷尽全部谱系，也不提供概率或准确率。

## 正式科学验收缺失的证据

需要取得该批数据的处理方法全文或作者配置，尤其是参考基因组/注释版本、样本混样与胚胎重复结构、原始细胞筛选和 doublet 处理方法。可继续进行软件兼容和敏感性试验；确认原研究复现或最终生物学注释时须补齐这些证据。
